💡 What:
Optimized the highly recursive `_normalize` function in `tools/learning_os/loading/yamlio.py` to early-return for common primitive leaf node types (`str`, `int`, `float`, `bool`, `None`).

🎯 Why:
The original implementation checked for `datetime` objects on every call, forcing an inline `import datetime` and an `isinstance()` call on every single scalar value in the repository's YAML files. By adding an exact type check (`type(value) is str`, etc.) at the top of the function before any expensive checks or imports, we skip all overhead for the most common node types.

📊 Impact:
Reduces overall runtime generation time by ~4% (total time across 5 samples dropped from 17.15s to 16.42s). The synthetic benchmark isolated for `_normalize` specifically showed a ~65% speedup on deep/large data structures.

🔬 Measurement:
1. Run `make test-fast` to ensure no changes to functionality.
2. Run `make check` to verify repository hygiene.
3. Run `.venv/bin/python tests/benchmark_runtime.py --samples 3` to verify read-only generation runtime improvement.
