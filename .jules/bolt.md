## 2026-09-09 - Exact Type Checks in Highly Recursive YAML Loads
**Learning:** When dealing with deeply recursive structure normalization (like YAML parsing output containing nested dicts and lists), using exact type checks (`type(value) is dict`, `type(value) is list`) combined with early returns for primitives (`str`, `int`, `bool`, `None`) is significantly faster (~40% improvement in microbenchmarks for this operation) than relying solely on `isinstance()`, which has more overhead for checking class hierarchies. `isinstance` can still be used as a fallback for custom classes and subclasses after exact types are handled.
**Action:** Prioritize exact type matching (`type(value) is X`) over `isinstance()` for primitive types and standard collections when optimizing highly recursive functions (like AST processors or tree visitors) to reduce overhead.
