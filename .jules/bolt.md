## 2025-02-23 - Fast path primitive type checking in highly recursive tree functions
**Learning:** In highly recursive functions like YAML normalization that process large trees, common paths for primitive leaf nodes (str, int, float, bool) should be checked via exact type matching (`type(value) is str`, etc.) before processing expensive collections or performing inline imports. This significantly reduces overhead, especially when parsing large datasets.
**Action:** When optimizing highly recursive Python functions, use exact type matching for primitive leaf nodes to reduce overhead, while retaining `isinstance()` for collections to maintain compatibility with subclasses (e.g. from YAML parsers). Furthermore, delay expensive operations like inline imports until after checking for standard collections.
