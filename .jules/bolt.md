## 2026-10-03 - Recursive _normalize performance in learning_os/loading/yamlio.py
**Learning:** In highly recursive functions like YAML parsers' normalization, checking types using exact primitive matching before inline module imports cuts the time per object load almost by half. The cost of calling `isinstance` for primitive types (str, int, float, bool) and importing the module dynamically inside loops added up significantly on a lot of objects. Using `type(x) is str` over `isinstance(x, str)` provides an easy speed boost in Python.
**Action:** When working on generic, recursive normalization or validation functions, process the leaf nodes (primitives like strings, numbers, bools, and None) first using exact type matching `type(v) is T`. Keep `isinstance` checks strictly for composite types (dict, list) where structural properties and subclassing semantics are crucial.
