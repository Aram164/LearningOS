## 2025-02-05 - Exact type matching early returns for recursive primitive checking
**Learning:** In highly recursive functions that process large parsed structures (like YAML trees), checking `isinstance(value, tuple_of_classes)` for primitive leaf nodes (especially when combined with dynamic imports at the top of the function) causes significant overhead. Dynamic imports inside the function body are evaluated on every single leaf, adding up massively over deep trees.
**Action:** Use exact type checking `type(value) in (str, int, float, bool) or value is None` as an early return for primitive leaf nodes. Move any heavy dynamic imports (like `datetime`) below the recursive collection checks (`dict`, `list`), ensuring they are only evaluated when strictly necessary for the rare object types, thereby preserving safety for `yaml` subclass collections while vastly speeding up execution.
