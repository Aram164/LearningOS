## 2023-10-14 - Optimize highly recursive YAML normalization
**Learning:** In highly recursive configuration parsing (like `_normalize`), common type checks (like `isinstance` for primitives, or `isinstance(dict)`) execute millions of times. `isinstance` is slower than `type(value) is dict`, and checking for rare subclasses (like `datetime`) via inline imports adds huge overhead if not preceded by exact matches for common types (str, int, bool, float, dict, list).
**Action:** Use exact type checks (`type(value) is X`) for common primitives (`str`, `int`, `float`, `bool`) and exact type checks for container types (`dict`, `list`) before falling back to `isinstance` for subclassed containers from external parsers (like YAML). This provides a fast path without sacrificing correctness for corner cases.
