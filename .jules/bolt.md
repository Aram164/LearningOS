## 2024-09-27 - Exact type matching for primitives in recursive functions
**Learning:** In highly recursive Python functions (like YAML normalization), `isinstance()` checks on leaf nodes add significant overhead. Checking exact types (`type(value) is str`) explicitly for primitives like strings, ints, floats, and booleans avoids running multiple `isinstance` checks, drastically improving performance. This is especially true since recursive functions process a huge number of leaf nodes.
**Action:** When optimizing highly recursive Python functions, use exact type matching (`type(value) is X`) for primitive leaf nodes (str, int, float, bool) to reduce overhead. Retain `isinstance()` for collections (dict, list) as a fallback to prevent functional regressions when handling subclasses.
