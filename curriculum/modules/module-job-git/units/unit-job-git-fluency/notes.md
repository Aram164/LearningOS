# Unit Working Notes

## Title

Git fluency — history, collaboration, and recovery

## Horizon

now

## Cadence

One 75–120 minute stage per week. Begin with a five-minute closed-book graph sketch, do every state-changing command only in a disposable practice repository, predict which refs and trees will move before pressing Enter, inspect the result with status/diff/log, then write one recovery note. Stratum is observation-only: status, diff, log, show, blame, branch, remote, and rev-parse are allowed; never switch, stash, reset, rebase, merge, clean, commit, or push there. Every fourth week, repeat one earlier failure drill without notes.

## Outcome

Given an unfamiliar repository state, independently draw the commit and ref graph, explain the working tree/index/HEAD/remote-tracking state, choose the least destructive command sequence, produce small reviewable commits and a clean pull-request history, resolve divergence or conflicts, and recover deliberately lost work from reflog. Fluency is evidenced by predictions, recovery drills, and a two-clone capstone—not by memorizing command recipes.
