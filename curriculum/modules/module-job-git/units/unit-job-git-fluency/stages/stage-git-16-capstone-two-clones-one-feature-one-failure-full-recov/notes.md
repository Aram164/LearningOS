# Stage Working Notes

## Mental Models

### Core model

Git fluency is the ability to preserve intent while manipulating snapshots and refs under collaboration pressure.

### Working practice

observe, draw, predict, act, verify, and record; the command is chosen only after the target graph and preservation requirements are explicit.

### Job relevance

the capstone rehearses the complete lifecycle of a Stratum-sized change without touching the real repository.

### Failure mode

succeeding only when the history follows a memorized happy path.

## Read-only Anchor

Stratum remains entirely read-only. Use only its existing history as a final archaeology example; perform the full capstone in a fresh disposable directory containing one bare upstream, one fork remote, and two clones.
