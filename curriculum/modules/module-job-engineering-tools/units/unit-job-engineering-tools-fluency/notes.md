# Unit Working Notes

## Title

The Missing Semester — engineering tools fluency

## Horizon

next

## Cadence

One 90–120 minute stage per week, or alternate with the Git track after Git Stage 3. Start every stage with a closed-book five-minute explanation, do shell/process/configuration experiments only in a disposable lab directory or isolated environment, record commands and exit status, then convert the useful result into a small repeatable artifact. Stratum remains read-only: inspect files, configuration, logs already produced, and history, but do not install tools, edit configuration, run mutating project commands, or change repository state. Every fourth stage includes retrieval of one earlier artifact on a clean shell.

## Outcome

Given a new development machine, remote host, unfamiliar repository, failing program, or release task, independently navigate and compose Unix tools, build safe shell automation, configure an editor and environment, debug and profile with evidence, package and ship reproducibly, enforce code quality, collaborate clearly, use coding agents within explicit authority and privacy boundaries, and explain the security model of the credentials and protocols involved. Fluency is evidenced by reusable artifacts and a clean-environment capstone, not lecture completion.
