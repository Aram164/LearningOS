💡 What: Added exact type checking for common scalar types (`str`, `int`, `float`, `bool`) and `None` to short-circuit the recursive `_normalize` function in `tools/learning_os/loading/yamlio.py`. Also moved the `datetime` module import to the file-level, eliminating the repeated import overhead inside the function.

🎯 Why: The original logic relied on successive `isinstance` checks for all elements traversing through YAML trees, including leaf nodes. Using `type(value) is T` check avoids the overhead associated with subclass checks, allowing primitives to quickly exit. Hoisting the `_dt` module from the scope of `_normalize` also saves checking `sys.modules` thousands of times per generation.

📊 Impact: Lowers load and generation time for parsed dictionaries. Tests executed via `tests/benchmark_runtime.py` showed a decrease from roughly `15.63` total seconds to `15.10` seconds, saving about half a second on execution over a ~3 sample median window.

🔬 Measurement: Run `.venv/bin/python tests/benchmark_runtime.py --samples 3` and observe the `"total"` property in `"median_seconds"` across outputs.
